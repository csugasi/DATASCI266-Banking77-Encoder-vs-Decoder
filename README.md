Labels vs. Scale: Breaking Even on Banking77 with Encoders and Decoders
How much labeled data does a small fine-tuned encoder need before it matches or beats a decoder language model on fine-grained intent classification?

We compare ModernBERT-base against Qwen2.5-1.5B-Instruct on the Banking77 dataset. The Qwen model is tested both zero-shot and fine-tuned with QLoRA, and both models are trained on the same examples at several data sizes.
